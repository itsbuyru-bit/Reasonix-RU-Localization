Неофициальная русская локализация **Reasonix Studio 2.47.x**. Добавляет
**«Русский»** в список языков приложения, переводит нативные поверхности
Electron и push-уведомления PWA.

Приложение **не пересобирается**. Инструмент правит вашу собственную установку,
хранит версионные резервные копии и умеет откатить все изменения.

> **Неофициально.** Проект не связан с Reasonix Studio / DeepSeek-Reasonix,
> не одобрен и не спонсируется его авторами. См.
> [Неофициальность](#неофициальность).

## Что переводится

| Поверхность | Перевод | Как |
|---|---|---|
| Окно Studio (веб-интерфейс Electron) | ✅ | Словарь в бандле `i18n-*.js` |
| Настройки → Язык | ✅ | Пара `` [`ru`,`Русский`] `` в `Settings-*.js` |
| Язык экрана запуска | ✅ | Патч `index.html` |
| Нативные поверхности Electron | ✅ | `app.asar`: запуск, контекстное меню, диалоги, трей |
| Push-уведомления PWA | ✅ | `push-sw.js` |
| Локальный веб/PWA-доступ с этой установки | ✅ | Отдаются те же файлы `frontend-next/dist` |
| Хостируемый Web Studio `reasonix.io/remote` | ❌ | Отдаётся сервером Reasonix, не вашей установкой |
| Go-бэкенд и CLI | ❌ | Строки скомпилированы в бинарник |

В проекте **нет исходников Reasonix, бандлов или бинарников**. Патчится только
установленная копия, перед изменением каждого файла создаётся резервная копия.

## Возможности

- **4 957 переведённых строк** — полный словарь, без пустых значений.
- **Пункт «Русский»** рядом с 中文 и English; выбор сохраняется.
- **Нативные строки** — экран запуска, контекстное меню, диалоги ошибок,
  диалог старой версии, меню в трее.
- **Push-уведомления PWA** — русские заголовки и тексты для подтверждений,
  вопросов модели, ошибок и прочих событий.
- **Безопасное патчение** — каждый якорь должен совпасть ровно один раз;
  при несовпадении скрипт останавливается **до** записи.
- **Версионные backup** — первая копия файла сохраняется как эталон для отката
  и не перезаписывается повторными применениями.
- **Откат одной командой** — пункт 4 меню.
- **Воспроизводимый конвейер** — извлечь → перевести → проверить → внедрить →
  проверить установленное.
- **Двуязычное меню** — русский по умолчанию, английский выбирается при
  запуске или флагом `--en`.
- **CI** — unit-тесты, проверка JSON и синтаксиса Node при каждом push.

## Поддерживаемая версия

| Компонент | Значение |
|---|---|
| Reasonix Studio | **2.47.x** — проверено на **2.47.1** |
| Веб-бандлы | `i18n-DS26LhWq.js`, `Settings-B_4tuZ4i.js` |
| PWA worker | `push-sw.js` |
| Нативный архив | `resources/app.asar` |

Номер версии не блокирует запуск. На другой сборке 2.47+ скрипт предупреждает и
всё равно проверяет все якоря; если якорь переехал, он останавливается до записи
и показывает, какой именно. Тогда обновите якоря в `scripts/inject_ru.py` (веб)
или `scripts/native_strings.py` (натив).

Обновление приложения заменяет пропатченные файлы, поэтому локализацию нужно
применить заново. См. [Обновление Reasonix](#обновление-reasonix).

## Требования

| Нужно | Зачем |
|---|---|
| **Windows 10/11** | Скрипты используют пути Windows и `tasklist`. |
| **Reasonix Studio 2.47.x** | Патчится ваша установка. |
| **Python 3.8+** | Все скрипты — стандартная библиотека. |
| **Node.js 18+** | Пересборка `app.asar` и проверка синтаксиса. |
| **Ключ DeepSeek API** | Только для перевода новых строк после обновления. Готовый словарь уже включён. |

`%APPDATA%\reasonix\.env` (переменная `DEEPSEEK_API_KEY`) и никогда не
попадает в репозиторий.

## Быстрый старт

1. **Полностью закройте Reasonix Studio** — включая значок в трее → **Выход**.
2. Запустите **`LOCALIZE-RU.bat`** из этой папки. Если Reasonix Studio
   установлен в `C:\Program Files`, нажмите на лаунчер правой кнопкой и выберите
   **«Запуск от имени администратора»**.
3. Выберите язык меню:
   - `1` — Русский (по умолчанию, можно просто нажать Enter)
   - `2` — English
4. Выберите **1 — Применить полностью**.
5. Запустите Reasonix Studio.
6. Откройте **Настройки → Язык → Русский**.

После смены языка окно перезагрузится. Если пункта **«Русский»** нет или
показан старый список, см. [Если что-то не работает](#если-что-то-не-работает).

### Только веб-интерфейс

Если не хотите трогать `app.asar`:

1. Запустите `LOCALIZE-RU.bat`.
2. Выберите **2 — Только веб-интерфейс**.
3. Перезапустите Studio (или перезагрузите окно) и выберите **Русский**.

Этот вариант можно применять при запущенном Studio; изменения проявятся после
перезагрузки окна.

### Английское меню сразу

```bat
LOCALIZE-RU.bat --en
```

Флаг `--ru` открывает русское меню без вопроса о языке.

## Меню

| Пункт | Действие |
|---|---|
| **1** | Применить всё: веб-интерфейс + нативный `app.asar` |
| **2** | Только веб-интерфейс |
| **3** | Проверить на копии, ничего не меняя |
| **4** | Откатить веб-файлы и `app.asar` из версионных backup |
| **5** | Пересобрать перевод из установленной версии (после обновления) |
| **6** | Сбросить кэш интерфейса Chromium (если виден старый Settings) |
| **7** | Выход |

Пункты 1 и 4 требуют полностью закрытого Reasonix Studio. Пункт 2 работает и
при запущенном приложении, но для результата нужен перезапуск окна.

## Как это работает

### Веб-интерфейс

Reasonix Studio — Electron-приложение, окно которого загружает локальную
веб-страницу. Словарь перевода лежит в минифицированном бандле `i18n-*.js`:

```js
var v = { zh: {}, en: { ... } };
```

**Ключ** — сам китайский текст, **значение** — перевод. Инъектор:

1. находит `i18n-*.js`, который реально подключён в `index.html`;
2. добавляет `globalThis.__RU = { ... }` и `v.ru = globalThis.__RU`;
3. учит функцию перевода `O()` смотреть в `__RU` при языке `ru`;
4. разрешает `ru` в резолвере языка и в `<html lang>`;
5. не даёт автоопределению языка перезаписать явный выбор `ru`;
6. добавляет `` [`ru`,`Русский`] `` в список языков бандла `Settings-*.js`;
7. правит язык экрана запуска в `index.html`;
8. переводит push-уведомления PWA в `push-sw.js`.

Каждая замена проверяется на **ровно одно совпадение**. Если якорь не найден,
скрипт сообщает об этом и не записывает файл.

### Нативные строки

`resources/app.asar` распаковывается, патчатся восемь файлов, проверяется
синтаксис, архив собирается заново:

| Файл | Что внутри |
|---|---|
| `uilang.js` | Принимает `ru`, определяет русскую локаль машины |
| `starting.js` | Заголовок и текст экрана запуска |
| `editmenu.js` | Пункты контекстного меню «Правка» |
| `hostexit.js` | Диалог «ядро неожиданно завершилось» |
| `shelllog.js` | Подсказки и диалог ошибки запуска |
| `packagegrants.js` | Диалог «не удалось открыть окно» |
| `main.js` | Диалог очистки старой версии |
| `tray.js` | Меню и строка состояния в трее |

Собранный архив проверяется повторной распаковкой и маркерами. Установка —
отдельный шаг `--install` с backup; при несовпадении якоря запись не происходит.

### Push-уведомления

В `push-sw.js` добавляется русский блок `TEXT.ru` и функция `pickLanguage()`.
Service worker не имеет доступа к `localStorage`, поэтому язык уведомлений
выбирается по `navigator.language` / `navigator.languages` (локаль браузера или
ОС), а не по переключателю в настройках. Для русской локали браузера
уведомления будут русскими.

### Безопасность и откат

- Перед изменением каждый файл копируется в `work/backup/<версия>/`.
- **Первая** копия файла сохраняется как эталон для отката; повторные
  применения её не трогают.
- `--restore` (пункт 4) возвращает файлы на место, включая `index.html` и
  `push-sw.js` из `dist`, а не из `assets`.
- Частичный или неудачный патч никогда не записывается молча.

### Кэш

Хост отдаёт хешированные файлы из `/assets/*` с долгим immutable-кэшем. Если
после починки всё ещё виден старый `Settings`, пункт **6** удаляет только кэши
Chromium (`Cache`, `Code Cache`, `GPUCache` и подобные). Настройки, темы,
сессии, `localStorage` и cookies не затрагиваются.

## Ручные команды

```bat
py scripts\extract_source.py
py scripts\translate_api.py --batch 20 --workers 6
py scripts\merge_parts.py --write
py scripts\review_terms.py
py scripts\verify_web.py --dict translations\ru.json
py scripts\patch_asar_ru.py --dry-run

py scripts\inject_ru.py
py scripts\patch_asar_ru.py --install

py scripts\inject_ru.py --restore
py scripts\patch_asar_ru.py --restore
py scripts\clear_cache.py
```

`inject_ru.py --dry-run` только проверяет веб-якоря. `patch_asar_ru.py
--dry-run` собирает и проверяет `work/asar/app-ru.asar`, но не устанавливает.

## Обновление Reasonix

Обновление приложения заменяет пропатченные файлы, поэтому русский пункт
исчезнет — это нормально.

1. Запустите `LOCALIZE-RU.bat`.
2. Выберите **5 — Пересобрать перевод из установленной версии**.
3. Скрипт:
   - извлечёт строки из новой установки;
   - переведёт **только новые** строки (готовые части переиспользуются, API
     тратится только на новое);
   - соберёт и проверит словарь;
   - проверит якоря на копии.
4. Если проверка прошла — **1 — Применить полностью**.
5. Если якорь переехал — скрипт остановится и покажет его. Обновите
   `scripts/inject_ru.py` (веб) или `scripts/native_strings.py` (натив) либо
   пришлите вывод в issue.

Уже переведённые строки сопоставляются по китайскому ключу. Если китайский ключ
изменился, строка считается новой и переводится заново. Если изменился только
английский эталон при том же ключе, старая русская строка сохраняется —
проверьте такие места в `work/ru_review.tsv`.

Номер версии — предупреждение, а не жёсткий блок: на новой сборке решение
принимают якоря.

## Если что-то не работает

### Пункта «Русский» нет или в списке «u» и «y»

Это был баг версий до **1.1.1**: пара языков вставлялась без квадратных
скобок, UI считал `ru` и `Русский` отдельными элементами и показывал их вторые
символы. Версия 1.1.1 добавляет правильную пару `` [`ru`,`Русский`] `` и
автоматически чинит уже повреждённый `Settings-*.js`.

Если обновляетесь со старой копии:

1. Полностью закройте Reasonix Studio.
2. Запустите `LOCALIZE-RU.bat` → **1 — Применить полностью** ещё раз (это
   починит файл), либо восстановите `work/backup/<версия>/` и примените заново.
3. Если старый список всё ещё виден, выберите пункт **6 — Сбросить кэш
   интерфейса** и запустите Studio.

### Интерфейс остался английским после выбора «Русский»

- Убедитесь, что выбран именно **Русский**, а не **Follow the system**.
- После смены языка окно перезагружается; дождитесь завершения.
- Сбросьте кэш (пункт 6) и перезапустите.
- Проверьте, что `translations/ru.json` найден: меню печатает путь и число
  строк при запуске.

### `app.asar` заблокирован

Reasonix Studio ещё работает. Закройте его полностью, включая значок в трее, и
повторите пункт 1 или 4. Сообщение об ошибке называет заблокированный файл.

### Отказано в доступе / приложение в Program Files

Если Reasonix Studio установлен в `C:\Program Files`, обычный пользователь не
может писать в `resources\...`. Патчер останавливается до изменения файлов и
печатает имя каталога.

1. Полностью закройте Reasonix Studio.
2. Нажмите правой кнопкой на `LOCALIZE-RU.bat` → **Запуск от имени администратора**.
3. Выберите пункт 1 или 2.

Сброс кэша (пункт 6) не требует прав администратора. Установка Reasonix Studio
вне `Program Files` тоже избавляет от проблемы.

### Не найден Python или Node

- Нужен Python 3.8+. `.bat` сначала пробует `py`, затем `python`.
- Нужен Node.js 18+ для `app.asar` и проверки синтаксиса. Без Node работает
  только веб-часть.

### Нет ключа DeepSeek API

Ключ нужен только для перевода/обновления. Добавьте его в
`%APPDATA%\reasonix\.env`:

```text
DEEPSEEK_API_KEY=...
```

Не вставляйте ключи в issues и pull requests. Без ключа существующий словарь
всё равно применяется; новые строки останутся на китайском.

### Хочу откатить всё

Закройте Reasonix Studio и выберите **4 — Откатить изменения**. Веб-файлы и
`app.asar` восстанавливаются из `work/backup/<версия>/`. Сброс кэша — отдельно,
пункт 6.

### Другая версия или переехали якоря

Скрипт печатает имя якоря и число совпадений. Не форсируйте запись. Обновите
якоря или откройте issue с полным выводом и версией Reasonix Studio. На новой
версии извлечение может работать, даже если для инъекции нужны новые якоря.

### Хостируемый Web Studio не переведён

`reasonix.io/remote` отдаётся сервером Reasonix. Патч действует только на
локальную установку. Локальный браузер/PWA-доступ, который отдаёт
`resources/frontend-next/dist` с вашей машины, переводится.

### Push-уведомления на другом языке

Service worker не читает язык приложения. Он следует
`navigator.language` / `navigator.languages`; выставьте русскую локаль
браузера/ОС или примите английские/китайские уведомления.

### Текст не помещается в узких элементах

Некоторые элементы рассчитаны на короткие английские подписи: фильтр проектов —
сегментированный контрол со шрифтом 10 px, а цена попадания в кэш — узкое поле
ввода. В версии **1.2.2** используются компактные подписи:

- фильтры проектов: `Все`, `В работе`, `Закреп.`, `Архив`;
- цена попадания в кэш: `Из кэша`;
- боковая панель настроек: `Модели`, `Сервисы моделей`, `Инструменты`,
  `Сообщения`;

`Сервисы моделей` — полный термин; в узкой панели он может обрезаться. При
необходимости используйте компактный вариант `Сервисы`.
- кнопка проверки подключения: `Тест`;
- наследуемые лимиты модели: в поле показывается только значение (`1,0M`,
  `Авто`, `Из настроек`) без префикса «Наследует…».

Если другой элемент всё ещё обрезается:

1. добавьте более короткий вариант в `translations/ru_overrides.json` и
   выполните `py scripts\merge_parts.py --write`;
2. примените локализацию заново (пункт 1 или 2) и сбросьте кэш (пункт 6);
3. размер интерфейса в **Настройки → Внешний вид → Размер интерфейса** меняет
   весь текст, а не только проблемный элемент; CSS-патч возможен, но привязан к
   сборке — пришлите скриншот в issue.

### Часть строк осталась на китайском

Отсутствующий ключ по задумке показывается по-китайски, а не пустым. Для 2.47.1
словарь полный, но новая сборка может добавить строки. Запустите обновление
(пункт 5), чтобы перевести их.

## Ограничения

- **Ориентировано на Windows.** Логика переносима, но пути и `tasklist` —
  Windows.
- **Якоря проверены на 2.47.x.** Новая сборка проверяется по якорям, а не по
  номеру версии; если они переехали, патч останавливается.
- **Go-бэкенд и CLI не покрыты.** Их строки скомпилированы в бинарник.
- **Обновление приложения стирает патч.** Нужно применить заново.
- **Диалог старой версии** (`main.js`) переводится по локали системы; он
  показывается крайне редко.
- **Язык push-уведомлений** зависит от локали браузера/ОС, а не от переключателя
  в настройках.
- **Хостируемый Web Studio** вне области: патчится только локальная установка.
- **Двуязычное меню, служебные логи на русском:** меню переключается на
  английский, но вывод Python-скриптов пока на русском.
- **Частичный словарь безопасен:** отсутствующие строки показываются
  по-китайски.

## Словарь и overrides

`translations/ru.json` — плоский объект:

```json
{
  "重命名聊天": "Переименовать чат",
  "聊天标题": "Название чата"
}
```

- **Ключи нельзя переводить.** Это ключи поиска.
- **Сохраняйте `{плейсхолдеры}`** (`{n}`, `{name}`, `{model}` и т.д.).
- **Не переводите названия продуктов**: Reasonix, DeepSeek, WeChat Pay,
  Alipay, GitHub, VS Code.
- Пустой исходник → пустое значение.

Точечные правки лежат в `translations/ru_overrides.json`. Они применяются поверх
машинного перевода и не требуют нового вызова API:

```json
{
 "工作台": "Верстак",
 "系统提示": "Системный промпт"
}
```

После правки выполните:

```bat
py scripts\merge_parts.py --write
```

`scripts/build_overrides.py` пересобирает текущие терминологические overrides
(`промпт`/`сессия`, «Верстак» и несколько коротких статусов). Не запускайте его,
если ведёте файл вручную: он перезапишет его.

Полный рабочий процесс — в [docs/TRANSLATION.md](docs/TRANSLATION.md).

## Проверка

```bat
py -m unittest discover -s tests
py scripts\verify_web.py --dict translations\ru.json
py scripts\patch_asar_ru.py --dry-run
node --check scripts\extract_bundle.mjs
node --check scripts\verify_push_sw.mjs
```

`verify_web.py` копирует frontend и `app.asar` в `work/test/app`, восстанавливает
исходные файлы из `work/backup/<версия>/`, если они есть, применяет словарь и
проверяет:

- переключение `ru` → `en` → `zh` через реальный ESM-бандл;
- возврат русской строки;
- работу английского словаря;
- китайский fallback;
- подстановку `{плейсхолдеров}`;
- пару языков в Settings, `index.html` и `push-sw.js`;
- service worker для `ru`/`en`/`zh`, fallback и счётчик;
- откат к исходным файлам.

Установленное приложение тест не меняет. CI запускает unit-тесты, проверку JSON
и синтаксиса Node при каждом push.
