# Support

Before opening an issue:

1. Read [README.md](README.md) and
   [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
2. Search existing issues.
3. If the language list is stale, quit Reasonix Studio completely and run menu
   option **6 — Clear the interface cache**.
4. Remove API keys, tokens, session data, and private code from anything you
   post.

Where to ask:

- **Bug in the localization or tooling** —
  [open a bug report](https://github.com/itsbuyru-bit/Reasonix-RU-Localization/issues/new?template=bug_report.yml).
- **Wrong or awkward translation** —
  [open a translation issue](https://github.com/itsbuyru-bit/Reasonix-RU-Localization/issues/new?template=translation.yml).
- **Security problem** — use
  [GitHub Security Advisories](https://github.com/itsbuyru-bit/Reasonix-RU-Localization/security/advisories/new),
  not a public issue.

This is an unofficial community project. Reasonix Studio itself is supported by
its own maintainers.
